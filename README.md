# 📘 Basic C Programming Algorithms (HSC Standard)

This repository contains simple C programming problems with their step-by-step algorithms following HSC standards.

---

## 🔹 Problem 1: Sum of Series
**Series:** 1 + 2 + 3 + ... + n  

### 🧠 Algorithm:
Start  
Declare integer variables: n, i, sum = 0  
Input value of n  
Set i = 1  
While i <= n, do:  
    sum = sum + i  
    i = i + 1  
Print sum  
End  

📂 Code: `problem1_sum_series/sum_series.c`

## 🔹 Problem 2: Even and Odd Numbers
**Print numbers from 1 to n as Even or Odd**

### 🧠 Algorithm:
Start  
Declare integer variables: n, i  
Input value of n  
For i = 1 to n, do:  
    If i % 2 == 0 → Print "Even"  
    Else → Print "Odd"  
End loop  
End  

📂 Code: `problem2_even_odd/even_odd.c`

## 🔹 Problem 3: Sum of Squares of Odd Numbers
**Series:** 1² + 3² + 5² + ... + n  

### 🧠 Algorithm:
Start  
Declare integer variables: n, i, sum = 0  
Input value of n  
Set i = 1  
While i <= n, do:  
    sum = sum + (i * i)  
    i = i + 2  
Print sum  
End  

📂 Code: `problem3_sum_odd_squares/sum_odd_squares.c`
